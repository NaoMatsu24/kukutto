# くくっと！

小学4年生向けの、問題数を選んで九九を練習できるWebアプリです。記録はブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで開いてください。ローカルサーバーを使う場合は、このフォルダーで次のコマンドを実行します。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

GitHub PagesなどのHTTPS環境で公開すると、対応端末ではページを開いた際に端末に合ったインストール案内が表示され、ホーム画面やパソコンへアプリとして追加できます。iPhone・iPadでは、案内に従ってブラウザの共有ボタンから「ホーム画面に追加」を選びます。一度オンラインで開いてインストールすると、数字入力と4択はオフラインでも使用できます。音声回答は端末や通信環境により、オフラインでは利用できない場合があります。

テストを始める前に、答え方を「数字で入力」「声でこたえる」「4たく」から選べます。数字入力は画面内に常に表示される数字ボタンを使うため、タブレットの標準キーボードは開きません。「声でこたえる」を選ぶと、テストが終わるまでマイクを使い、音声認識が一時停止した場合も自動で再開します。ブラウザにマイクの使用を許可してください。音声入力に対応していない環境では、音声回答の選択肢が使用不可になります。

問題数は「10問・ちょこっと（おすすめ）」「20問・しっかり」「30問・たっぷり」「連続正解チャレンジ」から選べます。「連続正解チャレンジ」は、まちがえるまで続き、全問正解でも100問で終了します。

テスト中に「テストをやめる」を押すと、確認後にホームへ戻ります。途中までの結果は記録されません。

回答後に次の問題へ進む時間は「0.5秒」「1秒」「2秒」「自分で進む」から選べます。初期設定は1秒です。選んだ設定はブラウザに保存されます。

「にがてな九九」ページでは、「今日の復習」または「苦手を練習」を選び、共通のスタートボタンから練習を始めます。これまでに間違えた問題のうち苦手な順に最大10問を練習でき、苦手問題が10問より少ない場合は記録されている問題だけを出します。

苦手問題の正答率が80％以上になると、克服した問題として「にがてな九九」の一覧から外れます。その後に間違えて正答率が80％未満になると、再び一覧に表示されます。

一度間違えた問題には、忘れかける頃に取り組める「今日の復習」が設定されます。間違えた場合は翌日、正解が続いた場合は3日後、7日後、14日後、30日後の順に復習間隔が長くなります。復習で間違えると、次の復習日は再び翌日になります。復習予定はほかの記録と同じくブラウザ内に保存されます。

記録ページは直近30件を標準で表示し、20件ずつページを切り替えられます。月別の絞り込み、月ごとの平均表示、全記録のCSV保存にも対応しています。

記録ページの「全データを保存」を押すと、テスト記録・苦手な九九・設定・九九ガーデン・花コレクションをJSON形式のバックアップファイルに保存できます。「バックアップを読み込む」から同じファイルを選ぶと、確認後に現在のデータを置き換えて復元します。

トップ画面の「九九ガーデン」は、テストを続けると、たねから特別な花まで7段階で育ちます。通常テストの完了で10ポイント、連続正解チャレンジ・今日の復習・苦手を練習・間違い直しでは挑戦した問題数に応じて最大10ポイントが増えます。さらに正答率、前回からの点数アップ、苦手問題の克服でボーナスポイントが増えます。ポイントをもらえるのは1日2回までで、休んでも植物は枯れません。

特別な花まで育つと「新しいたねをうえる」ボタンが表示されます。ボタンを押すと新しい植物が種から始まり、累計ポイント、練習日数、完成した花の数はそのまま残ります。

完成した花は、ガーデン画面の「お花コレクション」に完成日と一緒に保存されます。新しい種を育て始めても消えません。「すべてのきろくを消す」を実行した場合は、花のコレクションも削除されます。

「すべてのきろくを消す」を押すと、削除される内容を説明する注意画面が表示されます。その画面で「本当にすべて消す」を押すまで、記録は削除されません。

ガーデン画面の「花がたまった見本を見る」を押すと、10個の花があるコレクション画面を確認できます。見本の花は実際の記録には保存されません。

植物の7段階には、オリジナルの日本の教材用クリップアート風イラストを使用しています。画像は `images/garden` フォルダーにあります。

完成する通常花は「ひまわり」「ピンクの花」「赤いチューリップ」「青いデイジー」「紫のパンジー」「オレンジのマリーゴールド」「白いコスモス」の7種類です。さらに「虹色のきらめき花」「月夜の星花」のレア花があり、5個目ごとに交互に登場します。完成した花は種類とレア表示を付けてコレクションへ保存されます。

## 自分のイラストに替える

現在は、息子さんが描いたキャラクターをメインに使い、不正解や注意の場面では「ガーン…」という悲しい顔へ変わります。悲しい顔は、横線の目、縦線、汗、黄色寄りのオレンジ色の嘴で表現しています。画像は `images/character` フォルダーにあり、元の絵も `original-drawing.png` として残しています。

別の画像へ変更する場合は、同じ名前の画像を差し替えるか、`app.js` の先頭にある `CHARACTER_PICTURES` を変更してください。画像がないときは、仮の笑顔イラストが自動で表示されます。

## 記録について

- 同じブラウザ・同じ端末で使うと記録が残ります。
- ブラウザのデータを消すと記録も消えます。
- 端末の交換やブラウザデータの削除に備えて、記録ページから全データのバックアップを保存してください。
- 7日間のグラフは、同じ日に複数回テストした場合、その日の最新結果を使います。
